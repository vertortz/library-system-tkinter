# Библиотечная система на Python и Tkinter

## Запуск

```powershell
python library_app.py
```

Данные сохраняются в SQLite-файле `library.db`.

## Учётные записи

- Администратор: `admin` / `admin123`
- Библиотекарь: `librarian` / `library123`

## Проверка логики

```powershell
python -m unittest test_library_app.py
```
